GEOMETRY

24×24 grid · 1.6px stroke · rounded line caps and joins. Two angle conventions: strict 90° for stable elements (truth) and −7° for elements that communicate weight or imbalance — matches the Tau crossbar.

COLOR

Default brass for navigation and primary actions. Semantic only when the icon is the meaning: verify-green for ✓, flag-amber for pending/lock, danger for hot. Never colorize a navigation icon.

EXTENSION RULE

New icons must match these conventions. Reject any glyph that requires additional ink (gradients, multi-stroke widths, drop shadows). The family should grow without anyone noticing the new arrival.

CLEARSPACE

Half the mark's height on every side

Never crowd the Tau. Reserve clearspace equal to ½ the mark's height on all four sides; no other element — type, photography, ruling — enters that area.

DO / DON'T

Treat the mark like an instrument

Eight rules. Most refer to a single principle: the tilt is intentional. Never correct it.

DO
Brass on paper. The default.
DO
Brass on ink. Instrument mode.
DON'T
Don't straighten the crossbar. The tilt is the brand.
DON'T
Don't recolor outside the brand palette.
DON'T
Never skew, italicize, or 3D-perspective the mark.
DON'T
No drop shadows, bevels, or "embossed" effects.
DON'T
Don't sit on busy or low-contrast backgrounds.
DON'T
Don't crowd clearspace with other type or marks.
